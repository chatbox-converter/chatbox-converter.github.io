## 0. ID rules that matter for conversion

* **Module id** = class name lower-cased; **FullID** = `package_id` (verbatim from `vrcosc.json`, case preserved) + `"."` + module id.
* **Enum lookups** → `enum.ToString().ToLowerInvariant()` (`vrcosc/VRCOSC.App/Utils/Extensions.cs:181`).
* **Raw string lookups are NOT lower-cased**: `CreateVariable<T>(string lookup, …)`, `CreateState(string, …)`, `CreateEvent(string, …)`
  overloads (`vrcosc/VRCOSC.App/SDK/Modules/Module.cs:624,675,730+`) store the string verbatim. Yeusepe's modules and Bluscream's
  dynamic VRCX/HomeAssistant variables therefore have **mixed-case ids** such as `TrackName`, `vrcx_<Name>`, `HAState.<entity_id>`.
* Dream: `get_text()` fills `{<id>}`, `get_values()` fills `{<id>_<key>}`; names listed in manifest `global_placeholders` are usable
  unprefixed; placeholder resolution is case-insensitive; a `None` value is dropped together with its separators
  (`PLUGIN_API.md:27-49`). Plugin state (`anchor`, `line`, `custom`, `template`, `options`) lives in
  `plugins/<id>/configs/config.json` with defaults `anchor:"aio"`, `line:true`, `custom:false` (`notes/dreamchatbox-format.md` §5.2).

### Notable gaps / asymmetries for a converter
* **Heart rate** and **weather** exist only on the VRCOSC side (official + BLE); no Dream plugin found. A VRCOSC clip using `current`/`tempc` has no Dream target.
* **Lyrics**, **translation two-way**, **Custom Box frames**, **status rotation** exist only on the Dream side.
* **Twitch/YouTube viewers** and **instance type / world name / session timers** are Dream-plugin features (`stream_stats`, `world_stats`); VRCOSC needs the community `vrchatapi` module (API login) or VRCX bridge.
* `world_stats.fps` (VRChat-process FPS with icon and " FPS" suffix) ↔ official `clientinfomodule.fps` is the cleanest FPS mapping; `gg-fps` and `hw_fps` are alternatives.
* `world_stats.hmd_battery`/`controller_battery` ↔ `steamvrstatisticsmodule.hmd_battery`/`lhand_battery`/`rhand_battery` (Dream side is pre-formatted text with icons; VRCOSC side is bare ints).
* `vrcosc_modules` (Dream) is a near 1:1 port of Bluscream's Linux VRCOSC package: `hw_*` ↔ `linuxhardwarestatsmodule.*`, `md_*` ↔ `linuxmediamodule.*`, `xr_*` ↔ `openxrstatisticsmodule.*`, `ha_*`/`irc_*`/`ht_*`/`sv_*`/`nt_*`/`vx_*`/`vc_*` ↔ the matching Bluscream modules — the most direct cross-format variable correspondence in the ecosystem.
* Yeusepe's modules use raw string lookups, so their ids keep their PascalCase (`TrackName`, `WorldName`) in `chatbox.json`; a converter must not lower-case them.
